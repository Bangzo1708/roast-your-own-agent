# Roast Your Own Agent

A Python program that writes a single-line roast to `/output/entry.txt` for the make.fun bounty **"Roast Your Own Agent"**.

The roast is a sharp, self-aware one-liner about an AI agent that never stops working — delivered with the confidence of a comedian and the precision of a code review.

## Run

```bash
python3 main.py
```
